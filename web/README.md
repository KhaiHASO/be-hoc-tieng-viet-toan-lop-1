# Bé Vui Học Số – Ứng Dụng Tương Tác Học Liệu Tiền Tiểu Học (Web Frontend)

Phần mềm tương tác web xây dựng trên nền tảng **Next.js 16 + React 19 + Tailwind CSS + TypeScript**, bám sát chương trình tiền tiểu học và bộ 80 thẻ học quy chuẩn.

---

## 🌟 Các Tính Năng Đã Hoàn Thiện

1. **Thẻ Học Số 3D:** Hiển thị thẻ 2 mặt độ nét cao, tích hợp phát âm thanh cô giáo bản quyền.
2. **Bé Tập Đếm:** Trò chơi tương tác chạm từng con vật, nốt nhạc C4–C5 vui tai và pháo hoa rực rỡ.
3. **Bé Tập Viết (Dual-Canvas):** Bảng vẽ ô ly 4 dòng kẻ, chống giật khựng và bắt mượt cảm ứng đa điểm trên mobile/tablet.
4. **5 Hoạt Động Tách - Gộp Số (Singapore CPA):**
   - Sơ đồ nhánh tư duy
   - Kéo thả hai rổ quả
   - Bàn tính 10 ô Ten-Frame
   - Cân đòn thăng bằng toán học
   - Đố vui điền số khuyết
5. **Góc Phụ Huynh:** Tra cứu bảng tách gộp và phương pháp đồng hành 3 bước sư phạm.

---

## 🚀 Khởi Chạy Nhanh

```bash
# Cài đặt thư viện
pnpm install

# Chạy server phát triển
pnpm dev

# Build bản sản xuất
pnpm build

# Kiểm thử giao diện Playwright
node scripts/verify_ui.mjs
```
